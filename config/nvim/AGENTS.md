# Guidelines: Neovim

## Important Paths

- Help Documentation: `$PDE_DIR/share/nvim/runtime/doc/`
- LSP Logs: `$HOME/.local/state/nvim/lsp.log`

## Code Style

- VimScript: `*.vim`
  - Skip `l:` prefix in local variable names
  - Use `#{}` syntax for dictionary literals
  - Use `..` for string concatentation
